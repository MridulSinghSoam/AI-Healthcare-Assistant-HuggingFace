# 🏥 AI Healthcare Assistant using Hugging Face

## Overview

This project implements an AI-powered Healthcare Assistant using Hugging Face Transformers and Prompt Engineering.

The assistant can:

- Answer medical questions
- Generate structured responses
- Demonstrate prompt engineering techniques
- Compare different LLMs

---

## Technologies

- Python
- Hugging Face Transformers
- AutoTokenizer
- AutoModelForCausalLM
- Google Colab

---

## Project Structure

- chatbot.ipynb
- report.pdf
- prompts/
- screenshots/

---

## How to Run

```bash
pip install -r requirements.txt
```

Run

```text
chatbot.ipynb
```
